# 📚 Education — Reference Library

A curated shelf of the books behind this program. These are the long-form
companions to the phases: where the program gives you the mental model, these
give you the depth.

> **Access:** The books live in a shared Google Drive folder, available to
> anyone in the BlocLabs organization. Sign in with your **BlocLabs email** and
> you'll have view access automatically — no request needed.

## How to use these

- **Don't binge.** Read the chapter that maps to the problem in front of you.
  *Designing Data-Intensive Applications* makes a lot more sense after you've
  hit a real consistency bug than before.
- **The program is the spine; the books are the depth.** Phase docs tell you
  *what* matters and *why*. These tell you the full *how*.
- **Bring it back.** If a book reframes how you think about something, add the
  insight to the relevant phase or track doc so the next person gets it too.
