# developer-onboarding

BlocLabs' learning program and reusable developer education material.

## Read first

- `README.md` for the learning-path structure and contribution context.
- The affected phase, guide, or principle before changing its curriculum.
- `GLOSSARY.md` when adding or changing shared terminology.

## Local invariants

- Keep curriculum guidance accurate, portable, and useful to a reader with only
  this repository cloned.
- Preserve the learning-path order unless the change explicitly revises its
  prerequisite relationship.
- Put a concept in its owning guide; use links rather than duplicating a lesson
  across phases or tracks.
- Do not treat examples as current production configuration, credentials, or
  operational authority.
- Keep external references attributable and use official primary documentation
  when teaching a tool or platform behavior.

## Validation

Check Markdown links, headings, and the affected curriculum references. Read
the rendered context around a change so a lesson remains understandable without
chat history.
